# RetrievalOutputFormatter - Xử Lý Đầu Ra Legal RAG

## Tóm Tắt Thực Hiện

Đã thành công xây dựng hệ thống xử lý đầu ra (Output Formatter) để chuyển đổi kết quả truy xuất (Retrieval) thành cấu trúc JSON có tổ chức, định hình dữ liệu để phục vụ bài toán so sánh tài liệu.

                 │ {clause_id, versions.v1, versions.v2}
                 ▼

┌─────────────────────────────────────────────────────────────────┐
│ Step 3: EXPORT                                                    │
│ ├─ Lưu file JSON                                                 │
│ ├─ Xuất dict cho xử lý tiếp                                      │
│ └─ In màn hình dễ đọc                                            │
└────────────────┬────────────────────────────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────┐
│ Step 4: USAGE (Tiếp theo)                                          │
│ ├─ Frontend: Hiển thị so sánh                                     │
│ ├─ Comparator: Phân tích chi tiết                                │
│ ├─ Evaluation: Tính metrics                                      │
│ └─ Storage: Lưu trữ kết quả                                      │
└─────────────────────────────────────────────────────────────────┘

## 📝 Công Dụng Thực Tế

### 1. So Sánh Tài Liệu Pháp Lý
```python
# Lấy 2 phiên bản của Điều 3
formatter = RetrievalOutputFormatter()
comparison = retriever.search_clause_with_both_versions("Dieu 3")
formatter.add_from_comparison_dict(comparison)

# Xuất JSON cho frontend
json_data = formatter.to_json()
# Sử dụng trong diff viewer, comparison UI, v.v.
```

### 2. Audit Trail / Traceability
```python
# Lưu detailed format để kiểm toán
formatter.save_json("audit_trail.json", detailed=True)

# Chứa: document_id, version, heading, chunk_count
# -> Biết được từ tài liệu nào, phiên bản nào
```

### 3. Batch Processing
```python
# Trích xuất nhiều điều khoản
clauses = ["Dieu 1", "Dieu 2", ..., "Dieu 10"]
for clause_id in clauses:
    comparison = retriever.search_clause_with_both_versions(clause_id)
    formatter.add_from_comparison_dict(comparison)

# Export toàn bộ
formatter.save_json("full_comparison.json")
# -> File chứa so sánh của tất cả 10 điều
```

### 4. Integration với Hệ Thống Khác
```python
# Lấy dict thay vì JSON
paired_data = formatter.to_dict(detailed=False)

# Pass cho API:
return {
    "status": "success",
    "data": paired_data,
    "statistics": formatter.get_comparison_summary()
}
```
